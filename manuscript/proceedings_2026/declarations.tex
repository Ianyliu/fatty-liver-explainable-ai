\section*{Data, code and preparation}
The underlying study data originate from Taiwan Biobank and ultrasound acquisition at MacKay Memorial Hospital, as described by \citet{yen2024fattyliver}. Access to patient images, metadata and trained weights is restricted. Reproducibility scripts separate those inputs from analysis, figure generation and manuscript preparation. AI coding and writing tools assisted preparation of validation checks, plotting code and manuscript drafts; the authors remain responsible for the final scientific content.
