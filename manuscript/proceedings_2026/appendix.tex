\section{Historical and implemented methodology}
The accepted abstract and original workflow describe hard-label regularized classifiers, ten-fold tuning and historical bootstrap uncertainty. The present analysis instead uses class-1 probability regression, fixed-alpha Ridge, and training-only five-fold Elastic Net selection. No current bootstrap intervals, significance tests or physician validation are reported. The unmodified original illustration and editable draw.io source are preserved as historical supplementary material; the main figure updates its labels to the implemented methods.

The current graph edge threshold is $>0.95$, whereas the source publication describes $0.995$. The supplied split09 checkpoint and preprocessing are fixed; no retraining or conformal-risk inference is performed. Before the frozen study, sampler repairs addressed column mapping, class-label normalization, budgets, seed/state handling and pool-capacity reallocation. Those repairs are implementation provenance, not changes made in response to the comparative findings.
